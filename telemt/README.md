# telemt

A Rust-based server that implements Telegram's MTProto proxy protocol, designed to help users bypass network restrictions on Telegram.

Official repository: https://github.com/zydou/telemt

Build architectures:

- aarch64-unknown-linux-musl
- aarch64-unknown-linux-gnu
- aarch64-apple-darwin
- x86_64-unknown-linux-musl
- x86_64-unknown-linux-gnu
- x86_64-apple-darwin

Download: https://github.com/zydou/cli-tools/releases?q=telemt
